# Support

EveryO is maintained as an open-source project. Support is provided publicly on a best-effort basis.

## Where to ask

- **Bug:** open a [bug report](https://github.com/krishanth7/EveryO/issues/new?template=bug_report.yml).
- **Feature proposal:** open a [feature request](https://github.com/krishanth7/EveryO/issues/new?template=feature_request.yml).
- **Architecture or usage question:** use [GitHub Discussions](https://github.com/krishanth7/EveryO/discussions).
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.

## Before requesting help

Please include:

- EveryO and Python versions;
- operating system and relevant hardware;
- installation method;
- a minimal reproducible example;
- complete error text with secrets and personal paths removed;
- whether CUDA or TensorFlow is installed;
- commands already attempted.

## Scope

Community support covers installation, documented APIs, reproducible defects, examples, and contribution questions. It does not guarantee private consulting, custom model development, debugging unrelated applications, hardware support, response times, or implementation of requested features.

Please do not contact maintainers privately for routine support. Public questions create searchable answers for everyone.
