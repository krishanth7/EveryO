# EveryO — मुक्त न्यूरल कंप्यूटिंग

**भाषा:** हिन्दी · [English](../../README.md) · [सभी भाषाएँ](../../README.md#documentation-in-10-languages)

EveryO न्यूरल नेटवर्क अनुसंधान, शिक्षा और पुनरुत्पादित किए जा सकने वाले प्रयोगों के लिए एक ओपन-सोर्स Python फ्रेमवर्क है। इसका NumPy-आधारित कोर टेंसर, स्वचालित अवकलन, न्यूरल लेयर, ऑप्टिमाइज़र और प्रशिक्षण सुविधाएँ प्रदान करता है। CUDA, TensorFlow और ONNX वैकल्पिक एकीकरण हैं।

## शीघ्र प्रारंभ

Python 3.9–3.12 आवश्यक है। रिपॉज़िटरी की मुख्य डायरेक्टरी में चलाएँ:

```bash
python -m pip install -e .
everyo doctor
```

## कार्यशील उदाहरण

```python
import everyo as eo
x = eo.tensor([2.0], requires_grad=True)
y = x * x
y.backward()
print(x.grad)
```

**अपेक्षित आउटपुट:**

```text
[4.]
```

यह `x = 2` पर `x²` के अवकलज का मान है। मॉडल और प्रशिक्षण के लिए [उदाहरण](../../examples/) देखें।

## तकनीकी दायरा

- **कोर:** NumPy, स्वचालित अवकलन, लेयर, अनुकूलन और सीरियलाइज़ेशन।
- **सत्यापन:** रिग्रेशन परीक्षण, संख्यात्मक जाँच और CPU बेंचमार्क।
- **एकीकरण:** वैकल्पिक CUDA, TensorFlow तुलना और ONNX निर्यात।
- **सीमा:** स्वतंत्र उत्पादन प्रमाणन अभी प्राप्त नहीं हुआ है। [योग्यता रिपोर्ट](../production-qualification-2026-11-09.md) पढ़ें।
