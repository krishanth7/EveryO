# EveryO v0.3.0 — CPU Research & Numerical Engineering

**Release type:** cumulative source and packaging checkpoint  
**Release date:** 2026-11-09  
**Python:** 3.9–3.12  
**Support scope:** CPU-first research and education

## Overview

This release versions the CPU-first engineering baseline that accumulated on
`main` after v0.2.0. It includes tensor and autograd improvements, diagnostic
utilities, dataset and experiment tooling, and extensive numerical tests.
Those features were developed on the main branch prior to this version tag;
this release is their reproducible, versioned snapshot.

## Included capabilities

- NumPy tensor operations, reverse-mode automatic differentiation, and neural
  modules with deterministic CPU examples.
- Numerical gradient checking, graph inspection, anomaly detection, and CPU
  quality/benchmarking utilities.
- Dataset and checkpointing tools, experiment reproducibility documentation,
  and model training APIs.
- Optional accelerator and interoperability APIs, which require their own
  dependencies and hardware validation.

## Verification

Install from this tag and run:

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
ruff check .
ruff format --check .
everyo doctor
```

## Known limits

EveryO is not independently production-certified. CUDA numerical kernels
cannot be qualified on CPU-only infrastructure. Performance results depend on
the tested hardware and workload. For operational evidence, consult
[`docs/production-qualification-2026-11-09.md`](../production-qualification-2026-11-09.md).

## Upgrade

`v0.3.0` follows `v0.2.0`. Review the existing public APIs before migrating
trained artifacts and rerun your own numerical regression tests.
