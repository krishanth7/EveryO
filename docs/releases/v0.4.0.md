# EveryO v0.4.0 — Model Research & Interoperability Checkpoint

**Release type:** cumulative source and packaging checkpoint  
**Release date:** 2026-11-09  
**Python:** 3.9–3.12  
**Support scope:** CPU-first research models and model interchange

## Overview

This version records the framework's existing language-model, fine-tuning,
multimodal experimentation and model interoperability interfaces in an
independently identifiable package version. Those APIs were already present
on `main` before the v0.3.0 tag. Accordingly, this version does not claim a
new model architecture or benchmark improvement over v0.3.0.

## Included capabilities

- Educational CPU-based decoder-only language model experiments.
- Fine-tuning and multimodal reference workflows.
- ONNX export of supported operations, with separate ONNX Runtime checks.
- Optional TensorFlow reference checks, model compression, quantization and
  profiling utilities.

## Verification

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
ruff check .
ruff format --check .
everyo doctor
```

The examples are intentionally small and CPU-friendly. Large-model accuracy,
GPU numerical execution, throughput at scale, and real-world model generality
have not been established by these examples.

## Upgrade

The core source APIs match the v0.3.0 checkpoint except for version metadata
and documentation; the versioned distribution identifies the model research
and interoperability snapshot for reproducibility.
